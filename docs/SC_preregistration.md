# 预注册：SUCCES 项目分析方案冻结记录

> 冻结时间：2026-11-06（在查看任何回归结果之前）
> 冻结方式：本文件随代码仓库提交，以 commit 时间戳为准
> 作用：防止看到结果后改假设、改词典、改因变量（p-hacking）

---

## 1. 研究问题

- RQ1 六个维度各自与互动率的相关方向和强度如何？
- RQ2 控制账号体量、时长与发布时间后，哪些关联仍稳健？
- RQ3 硬核科普 vs 通识/学习方法类内容，起作用的维度是否不同？

## 2. 方向性假设（六条，均预设正相关）

| 编号 | 假设 | 依据 |
|---|---|---|
| H1 | Simple 与互动率正相关 | SUCCES 框架：核心主张单一有助于理解与记忆 |
| H2 | Unexpected 与互动率正相关 | 框架：打破预期制造信息缺口；中文 B 站实证发现疑问句式显著 |
| H3 | Concrete 与互动率正相关 | 框架：具体可感知的信息降低加工成本 |
| H4 | Credible 与互动率正相关 | 框架：可核验依据提升采信 |
| H5 | Emotional 与互动率正相关 | 框架：情绪唤起促进行动 |
| H6 | Stories 与互动率正相关 | 框架：叙事推动理解与分享 |

**六条方向一致，不做单维的差别化预期。** 未获支持的假设照实报告效应量与 95% 置信区间，
不删除、不改写方向、不回头调整词典。证伪同样是对框架适用边界的有效信息。

## 3. 因变量与主要检验

- **主因变量（唯一）**：`engage_rate = (like + coin + favorite + share + reply) / view`
- 次要/探索性：`fav_rate`、`share_rate`、RQ3 分组回归 —— 一律标注为 exploratory
- 不用播放量作因变量：播放量主要反映平台分发，会混淆内容特征与流量分配
- 主检验：六维标准化得分的回归系数，报告效应量与 95% CI，不做「显著/不显著」二分

## 4. 样本与剔除规则

- 抽样框：B 站知识区公开榜单（分区 × 时间窗分层交错取样）
- 正式样本目标 200-300 条；pilot 阶段 20-30 条仅用于链路自检，结论不进报告
- **2026-11-06 变更 C**：本轮 MVP 目标 120 条、锁定单一子区「社科·法律·心理」，实收 33 条（缺口 87），分层改为热度层 × 主题层；详见下方变更记录与 `docs/SC_sample-scope.md`
- **2026-11-06 变更 D（最终范围）**：数据源不走 Kaggle/和鲸；领域锁定「社科·法律·心理 & 科学科普」两区（`rid=124 + rid=201`）；时间不做强制要求，历史快照窗口纳入口径。详见 `docs/SC_sample-scope.md` 与 `SC_alt-datasets.md`。
- 剔除：非知识类（人工判定并记录理由）、时长 < 60 秒、重复 bvid、接口返回失败的条目
- **新增可审计标记**：`within_1yr`（≤365 天）、`view_usable`（view>0）、`rate_stable`（view≥1000）、`analysis_eligible`、`title_auto`（直播切片/自动命名）；本轮**不硬删**，正式分析须显式声明采用哪个口径
- **慎用 `view >= 1000` 筛选**：按与结果相关的量筛样本会引入选择偏差，正式分析需做一次不筛播放量的敏感性对照
- 每条记录采集时间；平台计数为快照，会随时间变化

## 5. 编码与词典

- 词典版本：`R/02_code_succes.R` 的 `LEX` **v0.2**（2026-11-06；pilot 28 条用的是 v0.1，结果保留供对照）
- 人工判定细则：`docs/codebook.md` **v0.3**（变更 E；只细化语义判定边界与正反例，**未改词典规则项**）
- 规则标注（词典 + 正则，可复现）+ 人工语义标注；编码时屏蔽结果变量
- 一致性：随机 20% 双人独立编码，Cohen's kappa 目标 ≥ 0.70（`R/SC_kappa.R`；模拟自检数值不得充作真实一致性）；
  **两位编码人必须是真实的人且互不可见对方答案**；kappa < 0.70 按第 8 节修订手册后重编，不事后改假设或调词典
- **冻结后不得增删词条**；若必须改动，在 changelog 记录时间、原因，并把改动前结果一并报告
- 人工指标未补齐前，维度得分只按规则项计算，并记录每维 `n_valid_items`，避免各维计分项数不同导致的不可比

## 6. 模型与稳健性（顺序固定）

1. 描述统计、六维得分分布、相关矩阵与 VIF
2. 主模型：`lm(log1p(engage_rate) ~ 六维标准化 + log1p(follower) + log1p(duration) + title_len + days_since_pub + pub_hour + pub_weekday + subzone)`，按 UP 主聚类稳健标准误
3. 稳健性：① 换收藏率 ② 去播放量极值 ③ 剔除账号属性项 Cr4 ④ 同一 UP 主固定效应
4. 异质性：按 `content_type` 分组回归（RQ3）
5. 多重比较：六维 × 多个因变量的检验需说明校正方式（FDR/Bonferroni）或明确以 CI 为主

## 7. 因果边界（全篇口径）

观察性横截面数据 + 推荐算法分发，混杂与反向因果无法排除。
全篇只写 `associated with / 与…相关`，不写「影响」「导致」「提升」。
真正的因果检验需另做标题 A/B 实验，列为研究下一步，不在本项目声称因果。

## 8. 变更规则

任何对上述条目的修改，必须：
1. 在本文件追加一条变更记录（日期、修改内容、理由、是否在看到结果之后）；
2. 保留修改前的分析结果供对照；
3. 若修改发生在看到结果之后，在报告「局限」一节显式说明为探索性调整。
