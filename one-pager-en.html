Origin: how else can knowledge reach us

Knowledge no longer lives only in classrooms. More researchers now package it into short videos, where a title and a short description have only a few seconds to win attention. In Made to Stick (2007), Chip Heath and Dan Heath proposed the SUCCES framework, a set of descriptive cues, not a tested causal law.

The question therefore narrows to two steps: can the six dimensions be measured reliably in public data? And once measured, how far do their associations with audience response go? Before asking "is there an association", we must first ask "can it be measured".

Six dimensions, operationalised as rule-item hits in titles and descriptions

SimpleH1Condensed, no redundant jargon.
UnexpectedH2Counter-intuitive or a curiosity gap.
ConcreteH3Grounded in numbers, units and examples.
CredibleH4Sources and verifiable evidence.
EmotionalH5Emotional arousal and personal relevance.
StoriesH6Characters, timelines and narrative cues.

Using only titles and descriptions, Credible and Stories both show almost no variation across thousands of records.

01 · M

Research method: four decisions made before looking at results

01 / Coding

Rule-items only

Each dimension takes the valid-item mean of 3 dictionary / regex rule items; two rounds of blind double coding showed subjective semantic items could not be reproduced reliably, so they were excluded before any results were seen. Missing subtitle and verification fields are recorded as NA — no guessing, no filling with 0.

02 / Data

Clean licences, frozen exclusion order

D1 (MIT): 5,717 records / 215 creators; D2 (Apache-2.0): 962 / 473, with SHA-256 logged on download. Deduplication and exclusion of non-positive engagement and missing values follow the pre-registered order; raw data with an Unknown licence are not distributed.

03 / Outcome

Two construct levels, two definitions

The main study uses log(engagement rate) = (likes + coins + favourites + shares + replies) / views, to avoid recommendation-driven exposure; the follow-up uses comment-level "informational discussion" (help-seeking question ∨ explanatory statement ∨ factual restatement), only a necessary-but-not-sufficient trace of information acquisition.

04 / Model & decision rule

OLS / LPM + clustered robust SE

Controls for views, duration, text length, publish time and account level; creator-clustered robust standard errors (hand-written sandwich in base R) + two-sided t + BH-FDR within the six hypotheses. Support requires β > 0 and q < 0.05.

Hypotheses: H1–H6 all pre-specified as positive, β > 0 and qBH < 0.05 count as support; Direction, model, exclusion order and the robustness checklist were frozen before any association result was seen; robustness checks judge direction only and are not used to hunt for new significant results. The only supported H3 effect is modest: 95% CI [+0.0274, +0.1508]; each +0.1 in Concrete corresponds to about +0.89% engagement rate, still positive and significant when switching to favourite rate or trimming extremes. Two deliberate exclusions: H2's raw p = 0.0337 → q = 0.1010 is not a finding; an extreme coefficient in the other dataset is a sparse artefact and not interpretable. This conclusion comes with three limitations:
BOUNDARY 01

Depends on account-level controls

Dropping creator fixed effects reduces H3 to +0.029 and it is no longer significant, while two other dimensions turn "significant" — without account controls the story would be completely different.

BOUNDARY 02

Not replicated across domains

In the other domain's 962 records, H3 = −0.0638 (q = 0.9429) and only 2 / 6 agree in direction: the external-validity check did not pass.

BOUNDARY 03

A measurement ceiling

s_credible 95.1% and s_stories 95.3% are zero; scaling from 64 to 5,717 records still leaves no variation — the bottleneck is operationalisation, not sample size.

Follow-up: With informational discussion in comments as the outcome, 0 / 6 were supported (H3 = −0.0120, q = 0.732), and all four robustness specifications agree in direction 6/6; explicit learning statements appear in only 13 / 2,773 comments (0.47%), so the construct we originally wanted is nearly unmeasurable in these top comments. Engagement rate, comment text and cognitive gain are three different construct levels — they do not contradict one another and cannot corroborate one another. This is "no positive association detected", not "SUCCES does not work".
Expand: how the results were produced

1. Data flow: only the last step produces coefficients

Main study SK_ · succes-kaggle/ 
SK_download.py   → data/external/*.zip              # download without login; log SHA-256
SK_prepare.py    → data/processed/SK_coded_D1.csv / D2.csv
                   # clean + 18 rule items + six dimension scores; descriptive checks only, no regression
R/SK_analyze.R   → output/SK_results.txt / SK_coefficients.csv / SK_robustness.csv
                   # the only step that produces beta / q / CI
Follow-up SW_ · succes-weekly/ 
SW_collect.py    → data/raw/SW_comments_{dev,main,control}.csv  # fetch public top comments by bvid
SW_prepare.py    → data/processed/SW_analysis.csv             # comment-level analysis table, one row per top comment
R/SW_analyze.R   → output/SW_results.txt / SW_coefficients.csv / SW_robustness.csv

"Preparation" and "inference" are strictly separated: the two *_prepare.py scripts explicitly compute no association between the six dimensions and the outcome; coefficients appear only in the R scripts. This lets us freeze definitions before seeing results and keeps every line auditable.

2. What the key code does

  • Codebook: SK_codebook.py / SW_succes.py port the LEX v0.2 dictionary and 18 rule items item by item; DIM_MAP maps three items per dimension; code_row() returns 18 items, the six dimension means and n_valid; u4 (subtitles) and cr4 (verification), when unavailable, are recorded as None. The dictionary is identical across the three studies — no new words, no changed thresholds.
  • Inference core: R/SK_analyze.R houses cluster_vcov(), which hand-builds the sandwich estimator V = adj · (X'X)⁻¹ · Σ_g(X_g'u_g u_g'X_g) · (X'X)⁻¹, using summary(fit)$cov.unscaled to skip aliased columns, with the small-sample correction G/(G−1)·(n−1)/(n−k); df = G−1 for two-sided p-values, then p.adjust(p, "BH"), and finally applies beta > 0 & q < 0.05 as the decision rule. Everything uses only base R's lm / pt / p.adjust.
  • Robustness: S1–S6 are written as a specs list and run once in the pre-registered order (favourite rate / share rate, trimming the top and bottom 1%, dropping creator fixed effects, cr4 set to 0, switching to D2); no subsets are chosen after the fact; R/SW_analyze.R reuses the same cluster_vcov(), marks aliased / NA coefficients as "not estimable", and flags the sparse artefact driven by 9 / 434 non-zero rows as sparse_flag, keeping it out of the conclusions.
  • Follow-up outcome: SW_info_markers.py defines info_discussion = ask ∨ explain ∨ fact (help-seeking questions / explanatory statements / factual restatements, all regex-based rule items); an audit of 180 development-set comments found almost no explicit learning statements, so the main outcome was changed before any association was examined and the development set was excluded entirely.

3. Conclusions

  • Main: 1 / 6 supported — H3 Concrete beta = +0.0891, q = 0.0292, 95% CI [+0.0274, +0.1508], about +0.89% engagement rate per +0.1; robust to favourite rate and trimming extremes, but dropping creator fixed effects leaves +0.029 non-significant, and D2 gives −0.0638 (q = 0.9429) with only 2 / 6 consistent in direction.
  • Follow-up: 0 / 6 positive associations detected — H3 = −0.0120 (q = 0.732); S1 / S2 / S4 / S6 agree in direction 6 / 6; explicit learning statements appear in only 13 / 2,773 comments (0.47%), so "viewers acquired information" is nearly unmeasurable in these top-liked comments.
02

Review: what we deliver is not an answer but a map of the boundaries

What we actually measured

We measured dictionary hits in titles and descriptions, not the constructs themselves or content quality; observational data cannot separate recommendation traffic, thumbnails, account size or reverse title edits, and the sample frame is not random.

Three conclusions we can draw

  • At the title level, the six dimensions are partly observable, with Credible and Stories almost absent.
  • The only association that holds is "Concrete": modest in size, dependent on account-level controls, and not replicated across domains.
  • At the comment layer, with informational discussion as the outcome, none of the six hypotheses showed a positive association.

Next step: move coding into the video content itself

Not by enlarging the sample, but by changing what gets coded: ASR subtitles, on-screen OCR and narrative-structure annotation, so Credible and Stories have a chance to be observed. A hard prerequisite is to rewrite the codebook and establish reliability before any modelling.

Reproduction

The analysis layer uses only base R, with no network access and no packages to install; full commands are in the repository's docs/REPRODUCE.md.

# SC_ · this repository
Rscript R/SC_mvp.R && Rscript R/SC_kappa.R
# SK_ · succes-kaggle/
python3 SK_download.py && python3 SK_prepare.py && Rscript R/SK_analyze.R
# SW_ · succes-weekly/ (read-only reproduction)
python3 SW_prepare.py && Rscript R/SW_analyze.R
This material cannot answer "Does SUCCES work?"; it can only answer which associations were detected, and which were not, under these reproducible operationalisations. It is better read as a descriptive heuristic than as a tested causal mechanism.
