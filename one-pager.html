缘起：知识还能以什么方式抵达我们

知识不只存在于课堂。越来越多研究者把知识装进短视频，而一条视频往往只有标题与简介这几秒争取注意力。Chip Heath 与 Dan Heath 在《Made to Stick》（2007）提出的 SUCCES 六法则，是一组描述性线索，不是已被检验的因果规律。

于是问题收窄成两步：六维能否在公开数据里被稳定测出？测出之后，与受众反应的关联能走多远？回答「有没有关联」之前，必须先回答「能不能测」。

六个维度，操作化为标题与简介上的规则项命中

简洁Simple凝练、去掉冗余术语。
意外Unexpected反常识或悬念落差。
具象Concrete落到数字、单位与实例。
可信Credible给出来源与可核验依据。
情感Emotional情绪唤起与切身关联。
故事Stories人物、时间线与叙事线索。

只靠标题与简介，可信与故事两维在数千条样本中几乎无变异。

01 · M

研究方法：四个在看结果之前定下的决定

01 / 编码

规则项-only

六维各由 3 个词典 / 正则规则项取有效均值；两轮盲法双编码显示主观语义项无法稳定复现，看结果前整体排除。无字幕、无认证字段一律记 NA，不猜值、不补 0。

02 / 数据

许可干净、剔除顺序冻结

D1（MIT）5,717 条 / 215 UP、D2（Apache-2.0）962 条 / 473 UP，下载记 SHA-256。按预注册顺序去重、剔除非正互动与缺失；许可 Unknown 的原始数据不分发。

03 / 因变量

两层构念，两套口径

主体用 log(互动率)＝（赞＋币＋藏＋享＋评）/ 播放，避开推荐分发；延伸用评论级「信息性讨论」（求解提问 ∨ 解释陈述 ∨ 事实复述），只是获取信息的必要非充分痕迹。

04 / 模型与判定

OLS / LPM + 聚类稳健

控制播放、时长、文本长度、发布时间与账号层；按 UP 主聚类的稳健标准误（base R 手写三明治）＋双侧 t ＋六假设内 BH-FDR。β > 0 且 q < 0.05 才算支持。

假设：H1–H6 全部预设正相关，β > 0 且 qBH < 0.05 才算支持； 方向、模型、剔除顺序与稳健性清单在看到任何关联结果前冻结，稳健性只判断方向，不用来另找显著结果。 而研究结果如下表所示：

唯一支持的 H3 效应温和：95% CI [+0.0274, +0.1508]，Concrete 每 +0.1 对应互动率约 +0.89%，换收藏率、去极值仍正向显著。两处主动不采用：H2 原始 p = 0.0337 → q = 0.1010 不算发现；另一数据集的极端系数为稀疏伪估计，不可解读。 其中，这条结论伴随着三条限制：
BOUNDARY 01

依赖账号层控制

去掉 UP 主固定效应后 H3 降到 +0.029 且不再显著，另两维反而「显著」——不控制账号会讲出完全不同的故事。

BOUNDARY 02

跨领域没有复现

另一领域 962 条里 H3 = −0.0638（q = 0.9429），方向一致仅 2 / 6：外部效度检验未通过。

BOUNDARY 03

测量天花板

s_credible 95.1%、s_stories 95.3% 为零；样本从 64 扩到 5,717 仍无变异，瓶颈在操作化而非样本量。

延伸：​换成评论层信息性讨论后 0 / 6 获支持（H3 = −0.0120，q = 0.732），四个稳健设定方向 6/6 一致；显式学习表述仅 13 / 2,773（0.47%），原想测的构念在此类热评中近乎不可测。互动率、评论文本、认知增益是三层不同构念，不矛盾也不能互证；这是「未检出正相关」，不是「SUCCES 无效」。
展开：结论是怎么跑出来的​​

一、数据流：只有最后一步产出系数

主体 SK_ · succes-kaggle/ 
SK_download.py   → data/external/*.zip              # 免登录下载，记 SHA-256
SK_prepare.py    → data/processed/SK_coded_D1.csv / D2.csv
                   # 清洗 + 18 规则项 + 六维得分；只做描述性体检，不碰回归
R/SK_analyze.R   → output/SK_results.txt / SK_coefficients.csv / SK_robustness.csv
                   # 唯一产出 β / q / CI 的地方
延伸 SW_ · succes-weekly/ 
SW_collect.py    → data/raw/SW_comments_{dev,main,control}.csv  # 按 bvid 抓公开热评
SW_prepare.py    → data/processed/SW_analysis.csv             # 评论级分析表，每行一条热评
R/SW_analyze.R   → output/SW_results.txt / SW_coefficients.csv / SW_robustness.csv

「准备」与「推断」严格分开：两个 *_prepare.py 明确不计算六维与因变量的任何关联，系数只在 R 脚本里出现。这样既能在看结果前冻结口径，也便于逐行审计。

二、关键代码在做什么

  • 编码表：SK_codebook.py / SW_succes.py 逐项移植 LEX v0.2 词典与 18 个规则项，DIM_MAP 每维 3 项，code_row() 返回 18 项、六维均值与 n_valid；u4（字幕）、cr4（认证）不可得即记 None。三个项目词典一致，不新增词、不改阈值。
  • 推断核心：R/SK_analyze.R 的 cluster_vcov() 手写三明治 V = adj · (X'X)⁻¹ · Σ_g(X_g'u_g u_g'X_g) · (X'X)⁻¹，用 summary(fit)$cov.unscaled 避开 aliased 列，小样本校正 G/(G−1)·(n−1)/(n−k)；df = G−1 算双侧 p，再 p.adjust(p, "BH")，最后按 beta > 0 & q < 0.05 判定。全程只用 base R 的 lm / pt / p.adjust。
  • 稳健性：S1–S6 写成 specs 列表按预注册顺序一次跑完（换收藏率 / 分享率、去两端 1%、去 UP 固定效应、cr4 设 0、换 D2），不事后挑子集；R/SW_analyze.R 复用同一个 cluster_vcov()，把 aliased / NA 系数标「不可估」，把 9 / 434 非零撑出的稀疏伪估计标 sparse_flag，不让它进结论。
  • 延伸因变量：SW_info_markers.py 定义 info_discussion = ask ∨ explain ∨ fact（求解提问 / 解释性陈述 / 事实复述，均为正则规则项）；开发集 180 条审计发现显式学习表述近乎 0 命中，故在看关联之前更换主因变量，并整体排除开发集。

三、结论​

  • 主体：1 / 6 获支持 —— H3 Concrete β = +0.0891、q = 0.0292、95% CI [+0.0274, +0.1508]，每 +0.1 约 +0.89% 互动率；换收藏率与去极值仍稳，但去掉 UP 主固定效应后 +0.029 不显著，D2 为 −0.0638（q = 0.9429）、方向一致仅 2 / 6。
  • 延伸：0 / 6 检出正相关 —— H3 = −0.0120（q = 0.732），S1 / S2 / S4 / S6 四个设定方向 6 / 6 一致；显式学习表述仅 13 / 2,773（0.47%），「观众获取信息」在这类高赞热评中近乎不可测。
02

反思：交付的不是答案，是一份边界地图

我们实际上测了什么

测的是标题与简介上的词典命中，不是构念本身或内容质量；观察性数据无法分离推荐流、封面、账号体量与反向改标题的路径，样本框也非随机。

能得出的三点结论​

  • 六维在标题层部分可观测，可信与故事两维几乎不出现。
  • 唯一稳住的关联是「具象」，效应温和、依赖账号层控制、跨领域未复现。
  • 换到评论层的信息性讨论后，六条假设一条也未检出正相关。

下一步：把编码推进到视频内容本体

不是再扩样本，而是换编码对象：ASR 字幕、画面 OCR、叙事结构标注，让可信与故事有被观测到的机会。硬前提是先重写编码手册、跑通信度，再谈建模。

复现

分析层只用 base R，不联网、不需安装包；完整命令见仓库 docs/REPRODUCE.md。

# SC_ · 本仓库
Rscript R/SC_mvp.R && Rscript R/SC_kappa.R
# SK_ · succes-kaggle/
python3 SK_download.py && python3 SK_prepare.py && Rscript R/SK_analyze.R
# SW_ · succes-weekly/（只读复现）
python3 SW_prepare.py && Rscript R/SW_analyze.R
这份材料回答不了「SUCCES 是否有效」，只能回答：在这几个可复现的操作化下，哪些关联被检出、哪些没有。它更适合作为描述性启发框架，而非已被检验的因果机制。
