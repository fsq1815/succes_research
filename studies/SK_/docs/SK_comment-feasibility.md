**唯一有真实大规模中文评论的是原神数据集**，但评论挂在「动态 Post」而非「视频」上：
`genshin_B_comments_clustered.csv` 字段只有 `Post_ID / Comment_Content / Cluster`，1,599 个 Post_ID 能 100% 配到
`genshin_B_posts_cleaned.csv`（有 `Content`、`Like_Count`、`Comment_Count`），**而 `genshin_B_videos_clustered.csv`
（含 `Video_Title`、`Amount_View`、`Amount_Like`）没有 ID 列，两张表之间没有连接键**。

> 因此：**不存在「把本项目已编码的 5,717 条视频标题 + 各自评论正文」拼起来的现成 Kaggle 数据集。**

## 3. 即使拿到评论正文，也还有三个方法学障碍

### 3.1 构念层级变了：生产侧 ≠ 受众侧
预注册的六个自变量是**创作者生产侧的内容特征**：标题/简介里是否出现具体数字、来源、故事线索等。
评论文本是**受众反应侧**。把同一套词典套上去，测的是「受众有没有在评论里提到这些元素」，
应命名为「受众回响 / 感知」指标，与 `SK_codebook.py` 里那六个 `s_*` 不是同一构念，
系数含义不同，不能叫「同样的六个系数」，也不能合并或与原系数比较。

### 3.2 机械内生性：用结果预测结果
主因变量 `engage_rate = (like + coin + favorite + share + reply) / view` **分子含 `reply`**。
若六维自变量由评论文本构造：评论越多 → 词典命中越多（计数口径下几乎必然）→ 与互动率机械正相关；
即便改用命中比例，评论本身是高互动的**结果**而非原因，反向因果与自愿发言选择偏差都在。
要缓解必须同时：因变量改用不含 `reply` 的分量、自变量用比例而非计数、控制评论数与账号层，
并承认这仍是关联而非识别。

### 3.3 会重蹈路径 C 的覆辙
想用评论补的恰恰是 `Credible`（可信）与 `Stories`（故事）两维——它们在标题层 95%+ 为零。
但「这条评论有没有体现信任 / 讲了个故事」正是**主观语义判断**，
`SC_` 项目两轮盲法双编码（kappa 未达标）已经证明这类指标在现有手册下不可稳定编码。
用关键词硬套到口语化、反讽、缩写、玩梗的评论区，效度只会更低。
**评论层不是捷径，反而更需要人工编码与信度检验。**

### 3.4 一个真正干净的设计（如果要做）
保留六维在标题/简介（自变量不变），把评论文本编码成**新的结果变量**：
「受众是否复述具体信息 / 引用来源 / 复述叙事 / 表达信任」→ 检验
`内容特征 → 受众回响` 六条**新**假设。这样六个自变量的系数仍是原来那六个口径，
且能正面回应「标题测不出故事性」的质疑。代价：必须换数据集、重新预注册、重新做人工编码信度。

## 4. 现有数据能做什么：评论「计数」代理诊断

`R/SK_explore_comment_proxies.R` → `output/SK_exploratory_comment_proxies.txt`
（**POST-HOC / 非预注册**，写在看过主模型结果之后，只用于可行性判断，不得当假设检验结论引用）。

用与主模型完全相同的公式与按 UP 主聚类稳健 SE，把因变量换成 4 个替代口径：

| D1 因变量 | H3 Concrete β | q_BH | 说明 |
|---|---|---|---|
| `engage_rate`（基线，含 reply） | +0.0891 | 0.0292 | 预注册主结果 |
| `engage_noreply`（剔除评论分量） | +0.0889 | 0.0316 | 几乎不变 → 主结论**不是**被评论数机械驱动 |
| `like_rate` | +0.0558 | 0.3426 | 拆成单一行为后不再显著 |
| `reply_rate` | +0.0650 | 0.4197 | 同上 |
| `danmaku_rate` | +0.1155 | 0.1278 | 同上 |

- 评论数在 `engage_rate` 分子中的占比：中位数 **1.8%**、均值 2.5%，≥10% 的视频仅 132/5,717（2.3%）。
- 六个维度的零比例（95.1% / 95.3% 等）在换任何计数因变量后**完全不变**——编码表输入只有标题与简介，
  **计数不含语义，救不了 Credible / Stories 的测量天花板**。
- D2 在所有替代因变量下 H3 仍为负、q ≈ 0.85–0.99，与「未复现」一致。

⚠️ 这些 p / q 未做跨分析族的多重校正，且是事后探索，**不得写进结果摘要或对外报告**。

## 5. 若要继续做的三条路径

| 路径 | 能得到什么 | 代价 / 风险 |
|---|---|---|
| **A. 维持现状 + 上报操作化瓶颈** | 已有「1/6 支持 + 未复现 + 测量天花板」的完整诚实结论 | 零额外工作；H4/H6 保持「不可估」 |
| **B. 换原神 Post 层做新研究** | 1,607 条动态 × 408K 条评论，可做「内容特征 → 受众回响」 | 单位是动态不是视频、无曝光量、CC BY-NC 非商业、游戏领域、需全新预注册 + 评论编码信度 |
| **C. 自采评论正文** | 用 B 站公开评论 API 给 D1 的 bvid 抓评论，能保住原有 5,717 条视频口径 | `SC_` 项目曾遇 WBI 签名 / `-352` / `-799` 频控；需评估接口条款与采集量、重新预注册、重新做语义编码信度；工作量最大 |

**当前建议：A**。理由：本项目的价值在于「先排除不可靠测量、再在大样本上定位测量天花板」这条方法学链条，
而不是凑齐六个显著系数；为 H4/H6 引入主观语义编码会退回路径 C 已否定的方向。
