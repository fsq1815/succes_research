## 3. 研究问题与假设（方向冻结）

- **RQ1** 六个维度各自与互动率的关联方向、强度如何？

- **RQ3** 同一套编码在 D1（泛领域头部创作者）与 D2（教育话题）里，方向是否一致？

| H5 | `s_emotional` 与互动率 | 正 |

## 5. 变量与样本

- 主因变量：`engage_rate = (like + coin + favorite + share + reply) / view`；建模用 `log(engage_rate)`。
  系数 `β` 解释为「自变量每 +1 单位，互动率乘以 exp(β)」，报告 `exp(β)-1` 与 95% CI。
- 次因变量（稳健性）：`fav_rate = favorite/view`、`share_rate = share/view`。
- **不用播放量作因变量**（播放量主要是推荐分发结果）。
- 自变量：六个 `s_*`（0–1）。
- 控制变量：`log(view)`（比例的分母，必须控制）、`log(duration)`、`title_len`、`pub_hour`、
  `pub_weekday`、`pub_month`（年月固定效应，替代无法计算的 `days_since_pub`）、`factor(up_mid)`（UP 主固定效应，替代缺失的粉丝数）。
- **剔除规则（按顺序，全部记录剔除条数）**：
  1. 按视频 ID 去重；
  2. `view >= 1000`；
  3. 互动计数非负且 `engage_rate > 0`（`log` 要求为正）；
  4. `duration > 0`、标题非空；
  5. 不因「太热 / 太冷」额外删样本；去尾部 1% 只作为稳健性，不替换主结果。

## 6. 推断规则

- 主模型（OLS，base R `lm`）：
  `log(engage_rate) ~ 六维 + log(view) + log(duration) + title_len + pub_hour + factor(pub_weekday) + factor(pub_month) + factor(up_mid)`
- 标准误：**按 `up_mid` 聚类的稳健标准误**（base R 手写三明治估计，不引入包依赖；聚类数在体检时报告）。
- 检验：**双侧 t 检验**，报告方向；系数为负即判该假设未获支持，不得改写成单侧。
- **多重比较**：对六条假设的 p 值做 Benjamini–Hochberg 校正（`p.adjust(..., "BH")`），报告 `q` 值。
- **支持判定（写死）**：`β > 0` **且** `q < 0.05` → 该假设「获得支持」；否则一律记为「未获支持」，
  并区分「方向一致但不显著」与「方向相反」。不得只报点估计达标、不得挑子集重算。
- 报告共线性诊断（VIF）；若某维 VIF > 5，在结论里注明该维系数需谨慎解读，但不从模型中删除该维。

## 7. 稳健性与外部效度（顺序冻结，不事后增删）

| # | 分析 | 判定用途 |
|---|---|---|
| S1 | 换 `log(fav_rate)` 作因变量 | 方向是否稳定 |
| S2 | 换 `log(share_rate)` 作因变量 | 方向是否稳定 |
| S3 | 去掉 `engage_rate` 两端各 1% | 是否由极端值驱动 |
| S4 | 去掉 UP 主固定效应、仅保留聚类稳健 SE | 是否依赖固定效应设定 |
| S5 | `cr4` 强制设 0（Credible 恢复 3 项）重跑 | SK-变更 B 的敏感性 |
| S6 | D2 用**完全相同的公式与剔除规则**重跑 | RQ3 跨数据集方向一致性 |
| S7 | 描述性：六个维度在两组样本里的均值 / 变异 / 零命中比例 | 解释哪些维度「测不出来」 |

稳健性结果**只用于判断主结论是否脆弱**，不得用来替换主结果或另挑一个显著设定当结论。

## 8. 因果边界与禁止事项

- 全篇只说「与……相关 / 关联」，**不写「影响」「导致」「提升」**。互动率受推荐流、封面、
  流量池、账号体量与反向因果（运营依数据改标题）干扰，本设计无识别策略。
- 不写「SUCCES 有效 / 无效」；测的是**标题与简介的文本特征**，不是法则本身，更不是内容质量。
- 不把 D1 的头部创作者样本外推到全平台；不把 D2 的单一教育话题外推到其它领域。
- 不写任何因果识别、A/B 实验、聚类稳健标准误之外的稳健推断宣称。
- 二手数据的采集口径由 Kaggle 上传者决定，**未知**；这一条必须写进局限，不得隐去。
