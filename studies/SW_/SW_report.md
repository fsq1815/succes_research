# SUCCES-Weekly 结果报告

> 版本：2026-11-07 ｜ 预注册：`docs/SW_preregistration.md` v1.0 ｜ 分析代码：`R/SW_analyze.R`
> **本报告只作关联解释。高赞热评不是全体观众，规则项命中不是真实认知增益，本设计无因果识别策略。**

## 0. 结论速览

**答案：没有检出正相关。** 按预注册 v1.0 写死的判定规则（`β > 0` 且 `q_BH < 0.05`），
六条假设中 **0 / 6 获得支持**。927 个知识类视频的 2,773 条高赞评论里，
SUCCES 六维得分与「信息性讨论」之间没有统计上可靠的正向关联。

| 关键事实 | 数值 |
|---|---|
| 主模型 N / 视频 / UP 主聚类 | 2,773 条评论 / 927 视频 / 335 个 UP 主 |
| 因变量基础率 | 20.4%（565 / 2,773） |
| 六条假设获支持 | **0 / 6** |
| 方向为正的维度 | 3 / 6（H2 Unexpected、H4 Credible、H5 Emotional） |
| 唯一名义显著 | H5 Emotional β=+0.1666, p=0.0256 → BH 后 **q=0.1538，按冻结规则不算发现** |
| 稳健性 | S1 / S2 / S4 / S6 与主模型方向 **6/6 一致**，各设定均 0/6 支持 → 零结果稳定 |
| 窄口径 `info_learn` | 13 / 2,773（0.47%），近乎恒 0 → 「观众获取信息」在公开高赞热评中**不可测** |

**这不是「SUCCES 无效」的证明。** 准确说法是：在这类数据、这一操作化、这一样本量下，
**没有检出可报告的正相关**；而且最初想测的那个构念本身就测不到。两件事必须分开写。

**与姊妹项目的关系**：`SK_` 项目在 5,717 条视频上发现 H3 Concrete 与**互动率**正相关
（β=+0.0891, q=0.0292）；本项目把因变量换成**评论里的信息性讨论**后，
H3 变为 −0.0120（q=0.732）。即「标题具体性 → 互动」这条关联
**没有延伸到评论层的信息讨论**。两个结果不矛盾，但也不能互相印证。

## 1. 为什么因变量不是「观众获取信息」

初始研究问题是「SUCCES 六要素是否与观众获取信息正相关」。在动手建模前，先拿**独立的词典开发集**
（60 个 bvid / 180 条高赞评论，已整体排除出所有推断分析）做逐条审计：

| 候选表述 | 开发集命中 | 核对结论 |
|---|---|---|
| 学到了 / 学习到了 / 涨知识 | **0 / 180** | 无 |
| 感谢科普 / 谢谢讲解 / 受益匪浅 | **0 / 180** | 无 |
| 记笔记 / 做笔记 / 小本本 | **0 / 180** | 无 |
| 明白了 / 懂了 / 才知道 / 原来如此 | 3 / 180 | **逐条核对均为叙事误报**：「才知道那是只义眼」「脑子懂了但手还是不会」等，与从视频获取信息无关 |
| 求解提问（请问/为什么/如何…） | 15 / 180 | 多数为段子或玩梗，只有少数是真正求解 |

完整逐条审计见 `output/SW_dev_dictionary_audit.txt`。

**解释**：每周必看的**高赞热评**是被点赞机制筛出来的神评论、玩梗和情感共鸣；
「我学到了」这类表达极少被顶到前排。因此：

- 窄口径 `info_learn`（显式学习表述）在样本内近乎恒为 0，**不能作因变量**，
  六个系数在它上面根本估不出来；强行跑等于编造。
- 主因变量改为 `info_discussion`：**高赞评论中是否出现信息性讨论**
  = 求解提问 ∨ 解释性陈述 ∨ 事实复述（全部为可复现规则项，见 `SW_info_markers.py`）。
  它是「获取信息」的**必要非充分**痕迹，**不等于认知增益**。
- 次因变量 `info_echo`（评论与标题+推荐语的字符 bigram Jaccard）连续、客观，
  但与六维同源于标题，**存在机械相关风险**，只作稳健性 S3、不作主结论。
- 这一口径变更发生在**看任何关联结果之前**，依据是开发集描述性审计，
  且开发集整体排除，已登记在预注册第 9 节。

> **如果用户要的是「观众真的学到了」，本数据回答不了**，需要普通评论（非热评）、
> 行为数据（收藏/复看）或实验/问卷；见第 6 节。

## 2. 数据与方法

| 项 | 说明 |
|---|---|
| 视频框 | Kaggle 每周必看 8,064 唯一 bvid（2019–2023），知识类白名单 999 个 |
| 样本 | `dev` 60（排除）/ `main` 939 / `control` 150（非知识类，仅 S5）；固定种子 20261107 |
| 评论 | 公开免登录接口按热度取 **每视频 3 条热评**（接口上限，非 10 条）；限速 1.1 s；无凭据、不绕过风控 |
| 自变量 | 六维 `s_*`：`SW_succes.py` 逐项移植 LEX v0.2 与 18 个规则项；`u4`/`cr4` 记 NA |
| 主因变量 | `info_discussion ∈ {0,1}`，评论级 |
| 控制变量 | `log(view)`、`log1p(duration)`、`title_len`、`blurb_len`、`pub_year`、`zone`、`rank`、`log1p(comment_like)` |
| 模型 | 评论级 LPM + 按 `up_mid` 聚类稳健 SE（base R 手写三明治）+ 双侧 t + 六条假设内 BH-FDR |
| 支持判定 | `β > 0` **且** `q_BH < 0.05`（预注册写死） |

逐步样本量与剔除数见 `output/SW_data_health.txt`；逐请求日志见 `output/SW_collect_log.txt`。

## 3. 主模型结果

M0：评论级线性概率模型，`y = info_discussion`，按 `up_mid` 聚类稳健 SE，
N = 2,773 / G = 335 / k = 32，六条假设内 BH-FDR 校正。

| 假设 | 维度 | β | SE | p | q_BH | 95% CI | 判定 |
|---|---|---:|---:|---:|---:|---|---|
| H1 Simple | `s_simple` | −0.0725 | 0.0578 | 0.2107 | 0.6320 | [−0.1863, +0.0412] | 方向相反且不显著 |
| H2 Unexpected | `s_unexpected` | +0.0192 | 0.0362 | 0.5968 | 0.7321 | [−0.0520, +0.0904] | 方向一致但不显著 |
| H3 Concrete | `s_concrete` | −0.0120 | 0.0350 | 0.7321 | 0.7321 | [−0.0808, +0.0568] | 方向相反且不显著 |
| H4 Credible | `s_credible` | +0.0263 | 0.0760 | 0.7297 | 0.7321 | [−0.1232, +0.1757] | 方向一致但不显著 |
| H5 Emotional | `s_emotional` | +0.1666 | 0.0743 | 0.0256 | 0.1538 | [+0.0204, +0.3128] | 方向一致但不显著 |
| H6 Stories | `s_stories` | −0.0926 | 0.2324 | 0.6904 | 0.7321 | [−0.5498, +0.3645] | 方向相反且不显著 |

**解读**

- 六条全部未获支持；方向为正的只有 3 条，且全部不显著。
- **H5 Emotional 是唯一原始 p < 0.05 的维度**，六条假设内 BH 校正后 q = 0.1538，
  按预注册写死的规则**不算发现**；在 S2 / S4 里 q 也在 0.14–0.19 之间，
  可作为未来研究的假设生成，但不能当结论引用。LPM 下 `s_emotional` 每 +0.1
  约对应信息性讨论概率 +1.7 个百分点（未经多重比较校正）。
- VIF 最高 2.35（`title_len`），无共线性警报。
- **测量天花板仍在**：`s_credible` 97.7% 为零、`s_stories` 98.8% 为零，
  H4 / H6 的检验功效本身很低，「不显著」**不能读成「无效应」**。
  这与 `SK_` 项目在 5,717 条样本上发现的同一问题一致：瓶颈在「只靠标题/推荐语」的操作化，
  不是样本量。
- 全篇只作关联解释；系数不含任何因果含义。

## 4. 稳健性

| 设定 | 与主模型方向一致 | 该设定下获支持 | 说明 |
|---|---|---|---|
| S1 按 `bvid` 聚类 | 6/6 | 0/6 | 不依赖聚类层级 |
| S2 视频级比例（经验 logit） | 6/6 | 0/6 | 不依赖评论级分析单位 |
| S3 `info_echo` 连续因变量 | 3/6 | 0/6 | 与六维同源，只作方向参考 |
| S4 去掉热评排序 / 点赞控制 | 6/6 | 0/6 | 结论不由 `rank`、点赞驱动 |
| S5 非知识类对照 | 2/6 | 0/6 | 稀疏，见下方警示 |
| S6 `cr4 = 0` | 6/6 | 0/6 | 不依赖 `cr4` 缺失处理 |

**零结果稳定**：S1 / S2 / S4 / S6 四个设定与主模型的六维方向全部一致，且都是 0/6 支持。
换聚类层级、换分析单位、去掉热评排序控制、改 `cr4` 处理，都没有变出显著结果。

⚠️ **S5 必须排除解读**：非知识类对照组里 `s_stories` 只有 **9 / 434 条非零
（3 个视频 / 3 个 UP 主）**，`s_credible` **434 条全为 0**（被 aliased，系数不可估）。
该设定下 H6 曾出现 β = +0.9318、q ≈ 0.0000 的「获得支持」，这是典型的**稀疏伪估计**，
已由 `R/SW_analyze.R` 的 2b 段显式标记为「不可解读」，并在
`output/SW_robustness.csv` 里以 `sparse_flag=TRUE` + `note` 留痕。
**不得作为发现、不得写进任何材料、不得与 main 比较。**

**S3 说明**：`info_echo` 与六维都从标题/推荐语派生，存在机械相关风险；
该设定下 6 条也全部未获支持、方向一致仅 3/6，只作参考，不作主结论。

## 5. 局限

1. **构念效度（最重要）**：`info_discussion` 是「围绕信息讨论」，不是「获取信息」。
   任何把结果读成「SUCCES 帮助观众学到东西」的说法都越界。
2. **选择偏差**：每周必看是平台精选；每视频仅 3 条高赞热评，是点赞机制筛出的头部，
   不代表全体观众、不代表全部评论，也不代表典型学习反应。
3. **接口限制**：公开免登录端点 `sort=2` 恒返回 3 条，`pn≥2` / `sort=0` 为空，
   `reply/main` 需 WBI 返回 -352（本项目不绕过）。评论关闭（`code=12002`）的视频自然缺失。
4. **时间错位**：视频 2019–2023 发布，评论抓取于 2026-11-07，是长期累计后的当日热评快照。
5. **数据源**：Kaggle 数据集许可 **Unknown**（原始 CSV 不分发）；`视频标签` 实为榜单推荐语
   （中位 11 字），比完整简介短，依赖长文本的 `cr3`/`st2`/`st4` 命中率系统性偏低。
6. **未观测分母**：不知道谁看过但没评论，无法计算真实获取率。
7. **多重比较**：只对六条假设内做 BH-FDR；稳健性设定之间未再做族校正，
   故稳健性只用于判断脆弱性，不用于另找显著结果。
8. **观测性数据**：推荐流、封面、账号体量、UP 主依数据改标题等混杂均未识别，无因果结论。

## 6. 若要把「观众获取信息」真正测出来

| 路径 | 能改善什么 | 代价 |
|---|---|---|
| 抓普通评论而非只取热评（`reply/reply` 楼中楼可行，但需多倍请求） | 学习类表述基础率会上升 | 请求量 ×4 以上；仍非随机样本 |
| 用行为代理：收藏率、投币率、复看/完播（若有） | 客观、有变异 | 测的是「有用/想再看」，仍非认知增益；`SK_` 项目已做过互动率 |
| 人工编码 + 双人信度（判断评论是否体现知识采纳） | 构念效度最高 | `SC_` 项目两轮盲法双编码已证信度不足，需重写手册并重训 |
| 问卷 / 实验（前测-后测） | 唯一能直接回答「获取」 | 超出公开数据范围 |

## 7. 可 / 不可声称清单

**可以写**：按 bvid 抓取公开高赞评论、预注册、六条方向性假设、BH-FDR 校正、
按 UP 主聚类稳健标准误、六个关联系数及其方向与显著性；
「显式学习表述在高赞热评中近乎不可测，故改用可复现的信息性讨论代理」；
「公开接口上限 3 条热评，未绕过风控」。

**不得写**：任何因果动词（影响/导致/提升/促进）、「SUCCES 有效」、
「观众获取了信息 / 学习效果更好」、把 3 条热评外推到全体观众、
把 `info_echo` 系数当主结论、隐去 `info_learn ≈ 0`、
隐去不复现或不利的稳健性结果、把稳健性里的极端稀疏系数当负向发现。
