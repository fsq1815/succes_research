# SW 预注册 v1.0 — SUCCES 六要素与高赞评论中的信息性讨论

> **冻结时点**：2026-11-07 15:03，主样本 `main` 正在采集中；**只看过 `dev` 集（60 视频 / 180 评论）的描述性基础率，未看过任何六维与因变量的关联、回归或显著性结果**。
> 本文件冻结之后，任何口径改动都必须在第 9 节登记并注明是否发生在看到结果之后。

---

## 1. 研究问题与构念边界

**RQ**：每周必看视频的标题/推荐语中，SUCCES 六要素的规则项得分，是否与其**高赞评论中的信息性讨论**正相关？

**这不是**「观众是否真的获取了信息」的直接测量。三层可观测代理与构念的关系：

| 指标 | 定义 | 与「获取信息」的关系 | 在本文中的角色 |
|---|---|---|---|
| `info_learn` | 显式学习/理解表述（涨知识、感谢科普、受益匪浅…） | 最贴近，但 `dev` 集 **0/180 命中** | **报告性证据**，预期近乎恒 0，不作因变量建模 |
| `info_discussion` | 求解提问 ∨ 解释性陈述 ∨ 事实复述 | 必要非充分：围绕信息讨论 ≠ 认知增益 | **主因变量** |
| `info_echo` | 评论与标题+推荐语的 CJK 字符 bigram Jaccard | 客观但可能与六维**同源机械相关** | 仅稳健性 S3，不作主结论 |

**边界（必须写进任何对外表述）**：高赞热评是点赞机制筛出的神评论/玩梗/共鸣，**不代表全体观众**；规则项命中不代表真实认知增益；本设计是横断面观察关联，**无因果识别策略**。

## 2. 样本框与数据源

- 数据源：Kaggle `zhuosun03/bilibili-must-watch`（`B_231009_1696842727.csv`，8,104 行 / 8,064 唯一 bvid，2019–2023 共 237 期）。**许可标记为 Unknown** → 原始 CSV 只作本地分析输入，不随仓库分发，来源与许可声明写入 `docs/SW_data-source.md`。
- 评论来源：公开免登录端点 `GET /x/v2/reply?type=1&oid=<aid>&sort=2&pn=1&ps=20`，固定限速 1.1 s，无 Cookie / 无 WBI / 不绕过 `-352`。
- **接口硬限制**：该端点 `sort=2` 恒返回 **3 条热评**（`pn=2`、`sort=0` 返回空，`reply/main` 需 WBI 返回 -352）。故每个 bvid 最多 3 条高赞评论，**不是需求初始设想的 10 条**；不用楼中楼冒充高赞评论。此限制如实记录，不绕过。
- 划分（固定种子 `20261107`，见 `data/raw/SW_sample_frame.csv`）：
  - `dev` 60 个知识类 bvid → **只用于词典开发，整体排除出所有推断分析**；
  - `main` 939 个知识类 bvid → **主分析样本**；
  - `control` 150 个非知识类 bvid → **仅 S5 外部效度对照**，不并入主样本。
- 知识传播类白名单（只看 `视频类型` 字段，不按标题关键词挑样本）：
  科学科普 / 社科·法律·心理 / 人文历史 / 人文·历史 / 数码 / 校园学习 / 财经商业 / 科工机械 / 计算机技术 / 软件应用 / 极客DIY / 野生技能协会 / 音乐教学 / 职业职场 / 社会。

## 3. 变量

**自变量（视频级）**：`s_simple, s_unexpected, s_concrete, s_credible, s_emotional, s_stories`，来自 `SW_succes.py`，逐项复制 `SK_codebook.py` 的 LEX v0.2 与 18 个规则项（路径 C 的规则项-only 口径）。人工语义项 `s1/u3/c3/cr1/st3/e4` 不采用。

**因变量（评论级）**：`info_discussion ∈ {0,1}`，来自 `SW_info_markers.py`：
- `ask`：含明确求解词，或含疑问词且句末有问号；
- `explain`：清洗后长度 ≥ 30 且含解释连接词（因为/所以/其实/原理/指的是/…）；
- `fact`：清洗后长度 ≥ 25 且含「数字 + 单位」；
- 三者取或。清洗统一去表情码 `[xxx]`、URL、多余空白。

**控制变量（冻结）**：
`log(view)`、`log1p(duration)`、`title_len`、`blurb_len`、`pub_year`、`factor(zone)`、`factor(rank)`、`log1p(comment_like)`。
控制 `rank` 与 `comment_like` 是因为热评排序本身与玩梗/长评论相关；控制 `title_len`/`blurb_len` 是因为六维规则项含长度项（`s2`）。

## 4. 数据源限制（预先登记，不事后补偿）

| # | 限制 | 处理 |
|---|---|---|
| SW-变更 A | 数据集无完整视频简介；`视频标签` 实为**榜单一句话推荐语**（中位 11 字、最长 40 字） | 作为 `blurb` 输入编码表，不新增词典词补偿；依赖长文本的 `cr3`/`st2`/`st4` 命中率会系统性偏低 |
| SW-变更 B | 无字幕、无 UP 主认证字段 | `u4 = NA`、`cr4 = NA`，按有效项均值计分并记 `n_valid_items`；`cr4=0` 仅作 S6 敏感性 |
| SW-变更 C | 视频发布于 2019–2023，评论抓取于 2026 | 评论是长期累计后的当日热评快照；写入局限，不做时间因果解释 |
| SW-变更 D | 公开接口每视频仅 3 条热评 | 如实记录；不补楼中楼、不声称「十条高赞」 |
| SW-变更 E | 评论功能关闭（`code=12002`）等接口失败 | 只记录、不重试、不绕过；失败视频自然缺失，报告实际 N |

## 5. 剔除规则（顺序冻结）

1. 按 `bvid` 合并视频元数据与评论；`dev` / `control` 不进入主模型。
2. 评论正文清洗后非空。
3. 视频元数据：`view > 0`、`duration > 0`、`title` 非空、六维得分非 NA。
4. 不按点赞数、评论长度或因变量取值做任何额外剔除；不 winsorize 主设定（去极值仅作 S4）。
5. 逐步记录剔除条数到 `output/SW_data_health.txt`。

## 6. 模型与推断

- **主模型**：评论级线性概率模型（LPM）
  `info_discussion ~ s_simple + s_unexpected + s_concrete + s_credible + s_emotional + s_stories + 第 3 节全部控制变量`
- **标准误**：按 `up_mid` 聚类的稳健三明治（base R 手写，与 `SK_analyze.R` 同一实现）；双侧 t 检验，自由度 `G-1`。
- **六条假设**（全部方向为正，冻结）：
  H1 Simple、H2 Unexpected、H3 Concrete、H4 Credible、H5 Emotional、H6 Stories，方向均为 `β > 0`。
- **多重比较**：六条假设内 BH-FDR 校正。
- **支持判定（写死）**：`β > 0` **且** `q_BH < 0.05` → 「获得支持」；否则记「未获支持」，并区分方向一致但不显著 / 方向相反。不得只报点估计、不得挑子集重算。
- 报告 VIF；若某维 VIF > 5，在结论注明需谨慎解读，但不从模型删除该维。
- 报告 `info_learn` 的样本内基础率与唯一取值；若近乎恒 0，明确写「该构念在公开高赞热评中不可测」，**不强行建模、不用它凑系数**。

## 7. 稳健性（顺序冻结，不事后增删）

| # | 分析 | 用途 |
|---|---|---|
| S1 | 改按 `bvid` 聚类稳健 SE | 是否依赖聚类层级 |
| S2 | 视频级比例因变量：经验 logit `log((hits+0.5)/(n-hits+0.5))` OLS | 是否依赖评论级单位 |
| S3 | 换 `info_echo` 连续因变量（控制 `title_len`/`blurb_len`，注明机械相关风险） | 方向是否稳定，**不作主结论** |
| S4 | 去掉 `rank` 与 `comment_like` 控制 | 是否由热评排序驱动 |
| S5 | `control`（非知识类）用完全相同公式重跑 | 外部效度 / 领域依赖 |
| S6 | `cr4 = 0` 重跑（Credible 恢复 3 项） | SW-变更 B 敏感性 |
| S7 | `info_learn` 描述性（不建模） | 报告窄口径为何不可用 |

稳健性只用于判断主结论是否脆弱，**不得替换主结果或另挑显著设定当结论**。

## 8. 因果边界与禁止事项

- 全篇只说「与……相关 / 关联」，**不写「影响」「导致」「提升」「促进获取」**。
- 不写「SUCCES 有效 / 无效」；测的是标题与推荐语的文本特征，不是法则本身。
- 不写「观众获取了信息」「学习效果好」；只写「高赞评论中出现信息性讨论的比例」。
- 不把 3 条高赞热评外推到全体观众或全部评论；不隐去 `info_learn ≈ 0` 这一发现。
- 不把 `info_echo` 的系数当主结论（自变量与它同源派生）；不把 S5/S6 的极端稀疏系数当负向发现。
- 不做任何事后改假设、挑显著子集、增删控制变量、换因变量当主结果的操作。
